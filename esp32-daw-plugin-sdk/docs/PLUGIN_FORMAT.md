# The `.espplug` package, format 1

A gzip-compressed tar (`<id>-<version>.espplug`), reproducible (fixed mtime / owner, sorted):

```text
manifest.json
lib/host-x86_64-linux/libdaw_plugin_<name>.a
lib/esp32s3/libdaw_plugin_<name>.a
licenses/LICENSE            the plugin's own license (its directory's LICENSE, else the SDK's for MIT plugins)
licenses/<files>            (optional) license texts of bundled third-party code
PROVENANCE.md               (optional) upstream sources, revisions, modifications
```

## manifest.json

Generated by `tools/package.py`: the descriptor (via `dawplug info`, so it cannot drift from the
code) plus packaging data.

| Field | Meaning |
| --- | --- |
| `schema`, `format` | descriptor JSON schema (1), package format (1) |
| `id`, `name`, `vendor`, `version`, `license`, `description`, `category`, `type` | identity |
| `apiVersion`, `apiMinor`, `requires.{abiMajor,abiMinor,sdk}` | ABI the library was built for |
| `stateVersion`, `maxVoices`, `capabilities{}` | behaviour the DAW and its UI rely on |
| `resources.{memFastBytes,memLargeBytes,cpuPermilleBase,cpuPermilleVoice}` | budget estimates |
| `parameters[]` | id, key, display, group, unit, type, scale, min, max, default, automatable, hidden, labels |
| `presets[]`, `keyNames{}` | factory presets, drum key names |
| `resourceSlots[]` | ABI 1.1: `{key, name, types: ["audio" / "file"], extensions}` per resource slot |
| `entry`, `libName`, `targets[]` | link information |
| `licenseFiles[]`, `provenance[]`, `dependencies[]` | licensing and origin |
| `ui` | `{"editor": "generic", "color", "icon"}`; custom editors: see below |
| `build` | SDK version, compilers, build machine |
| `files{path: {sha256, size}}` | checksums of every other file in the archive |

## Checks at packaging (and again at import in the DAW)

- the entry symbol is the only global symbol defined by each library;
- undefined symbols are limited to libm, `mem*`, `str{len,cmp}` and compiler runtime helpers
  (`__*`): no allocation, stdio, threads, RTOS or exception machinery (docs/REALTIME_RULES.md);
- both target architectures are present; checksums match; ABI major is compatible.

The manifest is **not** a security boundary: a package is native code linked into the firmware.
Only import packages you trust, as you would any source dependency.

## Custom editor UIs (reserved)

`ui.editor = "generic"` makes the DAW build the panel from the parameter list (knobs, selectors,
groups). A future `"custom"` editor will be a declarative layout (JSON: controls bound to parameter
keys, positions, images from the package) rendered by the DAW's own components — never HTML or
script from the package, so a plugin cannot inject content into the browser.

## Runtime installation

Not supported in format 1: the device cannot execute an uploaded package. Packages are imported
into the DAW source tree and the firmware is rebuilt (DAW `scripts/import-plugins.sh`). Dynamic
loading (Espressif `elf_loader`) is a separate experimental milestone.
